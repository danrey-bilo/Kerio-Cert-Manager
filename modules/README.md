# Модули

Копии модулей EAMS: код, `module.json` с версией и правила сборки. Модули развиваются в своих репозиториях,
в проект попадают копией на закреплённой версии:

```bash
dotnet run tools/copy-module/copy-module.cs -- ../module-core
```

| Модуль | Версия | Что это |
|---|---|---|
| `audit` | 0.9.2 | Журнал действий: только дописывается, держится цепочкой хешей, пишет отказы прав и замечает массовый вынос секретов. |
| `core` | 0.10.0 | Ядро модулей: подключение модуля к приложению, конверт ошибок, «кто вошёл», проверка прав, журнал и настройки как контракты, транзакции, постраничность. |
| `crypto` | 0.5.0 | Шифрование секретов конвертом, мастер-ключ с ротацией, подпись целостности, печать на ключ устройства, подпись сборок. |
| `hosting` | 0.6.1 | Конвейер веб-хоста: номер обращения, конверт ошибок, личность запроса, проверка прав на каждом эндпоинте, контекст журнала, описание контракта OpenAPI, готовность, замок одного экземпляра, логи без текста исключений. |
| `identity` | 0.10.1 | Пользователи, вход, пароли (Argon2id), второй фактор (TOTP и код письмом), приглашения, сброс пароля, доверенные устройства. |
| `mail` | 0.10.0 | Очередь писем: шаблоны на трёх языках, отправка по SMTP с повторами, пределы частоты, секреты почты под шифрованием. |
| `settings` | 0.8.2 | Настройки системы и личные предпочтения: каталог объявлений модулей, три слоя значений, экран администратора. |
| `tokens` | 0.8.2 | Сессии и ключи API: выпуск, проверка, обновление с ротацией, отзыв, сужение прав ключа, уборка. |
